# Supply-Chain-Analysis
This project analyzes a supply chain and logistics dataset using Python and Power BI. It includes data cleaning, trend analysis, and interactive dashboards to visualize sales, inventory, shipping, and defect rates. The goal is to optimize operations, reduce costs, and provide actionable insights for decision-making.

## Problem Statement
The challenge is to clean, analyze, and visualize the data to uncover trends, identify inefficiencies, and support data-driven decisions for improving supply chain performance.

## Tools and Technologies
- **Python**: Data cleaning, manipulation, and visualization using libraries like Pandas, NumPy, Matplotlib, and Plotly.
- **MySQL**: Writing queries to analyze supply chain metrics and extract insights.
- **Excel**: Building static dashboards and visualizations for summary reporting.
- **Power BI**: Creating dynamic, interactive dashboards to explore the data in detail.

## Key Objectives
1. Analyze revenue generation, manufacturing expenses, and transportation costs.
2. Optimize inventory levels and reduce lead times.
3. Identify trends in defect rates and improve product quality.
4. Explore shipping performance to minimize logistics costs.

## Features
### Python Analysis
- Data Cleaning: Addressed missing values and ensured data consistency.
- Exploratory Data Analysis: Discovered key patterns in sales, inventory, and shipping.
- Interactive Visualizations: Created charts for customer demographics, lead times, and defect rates using Plotly.

### MySQL Analysis
- Calculated total revenue by product type.
- Analyzed shipping costs by carrier and transportation modes.
- Ranked products by profitability using revenue, manufacturing, and shipping costs.
- Assessed supplier performance based on lead times and defect rates.

### Excel Dashboard
- Built summary visualizations to track revenue, shipping costs, and defect rates.
- Highlighted trends in regional product demand and carrier efficiency.

### Power BI Dashboard
- Developed interactive dashboards with filters and slicers for:  
  - Total revenue, average price, and products sold.  
  - Manufacturing costs and lead times by product type.  
  - Transportation modes and shipping carrier performance.  

## Key Insights
- **Revenue**: Skincare products generate the highest revenue, contributing 45% of the business.
- **Logistics**: Carrier B is the fastest but costlier option; road transportation is the most efficient.
- **Defects**: Haircare has the highest defect rate at 37%, indicating a need for quality improvements.
- **Customer Demographics**: Female customers prefer skincare and cosmetics, while male customers focus on haircare.

## Conclusion
This project demonstrates the effective use of Python, MySQL, Excel, and Power BI to analyze and optimize supply chain operations. By addressing inefficiencies and visualizing key metrics, it provides a scalable framework for improving logistics, inventory management, and profitability.
